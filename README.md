# pendecia_fiscal_receita

Automação em Python para consulta controlada de pendências fiscais no Portal de Serviços da Receita Federal, com integração a uma planilha Excel existente.

> Estado inicial: repositório criado vazio em 2026-09-11. A implementação será desenvolvida em branch de trabalho. Nenhum certificado, senha, PIN, sessão autenticada, planilha real ou relatório fiscal deve ser versionado.

## Arquivos do protótipo ainda necessários

Para preservar e migrar fielmente o protótipo anterior, é necessário disponibilizar no repositório, sem dados sensíveis:

- `worker.mjs` usado pela automação anterior;
- código-fonte anterior da pasta `pendencias-fiscais-prototipo`;
- uma cópia sanitizada da planilha `.xlsm`, mantendo estrutura, fórmulas, macros e botões, mas sem empresas, CNPJs, resultados ou relatórios reais.

A planilha real continuará somente no Windows onde a automação será executada.
